# 随手问

**一次性的问题都在一个置顶对话里问，侧栏只留长期项目。**

和手头项目无关的碎片问题，不用每次新开窗口。开一个「随手问」对话置顶，问完就放着；默认每题独立回答，不被上一题带偏。问着问着觉得有用，说一声「存档」，助手把这个话题写成知识卡片，连你发过的原话一起存进本地笔记库。

配套技能：[一句话归档](https://github.com/Professormin/allinone/tree/main/yijuhua-guidang)（发一句就存，不聊天）。

## 复制这句话安装

```text
请帮我安装「随手问」：https://github.com/Professormin/allinone/tree/main/suiwen
```

## 装好后怎么说

| 你想做什么 | 你可以这样说 |
| --- | --- |
| 问一个一次性问题 | 直接问 |
| 接着上一题深入 | **接着问：……** |
| 把这个话题存成卡片 | **存档** |

## 各家 AI 怎么装

| 你在用的 | 怎么装 |
| --- | --- |
| Claude（网页 / 桌面） | 设置 → 功能 → 技能 → 上传，选仓库 `zip/` 文件夹里的 zip |
| Claude Code | 把文件夹放进 `~/.claude/skills/` |
| Codex | 把文件夹放进 `~/.codex/skills/` |
| Cursor、Gemini CLI 等 | 放进各自的技能 / 规则目录 |
| ChatGPT、豆包等（不支持技能） | 把 `SKILL.md` 正文贴进自定义指令；网页版不能运行命令，存的时候会给出代码块让你手动保存 |

需要 Python 3（脚本只用标准库）。建议设置环境变量 `SUIJI_ROOT` 指向你的笔记库文件夹；不设的话，第一次用时助手会问你一次。
