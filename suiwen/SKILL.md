# 随手问

用法：开一个对话，命名「随手问」，在侧栏置顶。以后所有一次性问题都在这里问，不再新开窗口，侧栏只留长期项目。

## 笔记库根目录
优先用环境变量 `SUIJI_ROOT`。没设时，第一次存档前问用户一次笔记库文件夹，之后在本对话里沿用。

## 回答规则
1. 每个新问题默认和前面的话题无关：只答这一题，不引用、不总结、不延续之前的话题。
2. 用户说"接着问/追问"或明显在追问上一题时，才接着用上一题的内容。
3. 回答简短直接，不主动扩写成长文，不主动提议存档。
4. 判断不了是新问题还是追问时，按新问题答。

## 存档（用户说"存档"）
"存档" 和 "归档" 意思一样 = 把当前这个话题写成知识卡片（两个词太像，一律当存档；从不用"归档"来隐藏对话）。

卡片格式：
```
# 知识卡片｜<主题>

存档日期 YYYY-MM-DD
存档分类 <一级分类> / <二级分类>
关键词 <3-6 个>

## 一、实际需求
## 二、已核实的结论或方法
## 三、做法 / 步骤
## 四、当前状态与待验证
## 五、用户原文
（这个话题里用户发的每一条，按顺序，原字原标点，一条不漏；和本话题无关的其他一次性问题不放进来）
```
只写有依据的内容；没核实的标"待验证"。

保存：
- 能运行命令：把整张卡片从标准输入传给
  `python <本技能目录>/scripts/suiji.py --root "<根目录>" --title "<主题>" --dir "<一级分类>/<二级分类>" -`
  最后一行是 `OK <路径>` 才算存好，回复只写一行：`已存 → <路径>`
- 不能运行命令，或输出 `FAIL`：明确说"没存上"和原因，把整张卡片放进一个代码块给用户，绝不说"已记住"。

存完继续当随手问窗口用，下一题照旧按新问题答。
