# 一句话归档

**发一句话，它就存进你电脑上的笔记库。不复述，不追问，只回一行路径。**

突然想到的点子、要记下的一句话，丢进置顶的「一句话归档」对话就行。每条按时间追加到 `00_随手记/YYYY-MM.md`；存不上会明说，绝不说"已记住"。手机或网页 AI 写的内容，存成 .txt 丢进收件箱，下次在电脑上会自动并入。

配套技能：[随手问](https://github.com/Professormin/allinone/tree/main/suiwen)（一次性问题在一个窗口里问，需要时存成知识卡片）。

## 复制这句话安装

```text
请帮我安装「一句话归档」：https://github.com/Professormin/allinone/tree/main/yijuhua-guidang
```

## 装好后怎么说

| 你想做什么 | 你可以这样说 |
| --- | --- |
| 存一句话 | 直接发内容 |
| 存一段有主题的内容 | 直接发，助手会单独存成一个文件 |
| 并入手机收件箱 | 下次在电脑上发任何一句时自动并入 |

## 各家 AI 怎么装

| 你在用的 | 怎么装 |
| --- | --- |
| Claude（网页 / 桌面） | 设置 → 功能 → 技能 → 上传，选仓库 `zip/` 文件夹里的 zip |
| Claude Code | 把文件夹放进 `~/.claude/skills/` |
| Codex | 把文件夹放进 `~/.codex/skills/` |
| Cursor、Gemini CLI 等 | 放进各自的技能 / 规则目录 |
| ChatGPT、豆包等（不支持技能） | 把 `SKILL.md` 正文贴进自定义指令；网页版不能运行命令，存的时候会给出代码块让你手动保存 |

需要 Python 3（脚本只用标准库）。建议设置环境变量 `SUIJI_ROOT` 指向你的笔记库文件夹；不设的话，第一次用时助手会问你一次。
