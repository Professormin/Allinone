# Deep Mechanism
Specific scenario/paradox → ordinary interpretation → key structural distinction → mechanism A and B → constraint/counterexample → viewer decision principle.
Never pass invented anecdotes for reported facts or speculative allegations for verified outcomes. Explicitly distinguish individual case, mechanism hypothesis, evidence and conclusion.
Example: distinguish a chat UI from a single agent, ongoing personal assistant, and multi-agent orchestration. Multiple agents may help separable parallel tasks and independent context but may cause merge, quality and coordination costs. No magic ideal agent count.
Model references: private vs public resource allocation; narrative labels vs observable structure; sequential editing vs independent regional research.
