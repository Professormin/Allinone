# AI Tool Introduction
Concrete hook/pain → product identification → verified capability → practical workflow/scene → limitation/cost → who should try.
Modes: brief news; 60–120 second orientation; in-depth tested review. Separate creator opinions from manufacturer claims, dated announcements, and tests; verify changing release dates/features/pricing. Avoid categorical 'best in world' statements as fact. Never claim tool use not performed.
Model references: voice generation models and open-source video-editing utilities.
HKRR emphasis: Knowledge and Rhythm, with relevance-based Resonance.
