# web-gallery-grabber · 网页图库一键存图

给一个网页地址，把上面的图片原图全部存下来：按图片的说明文字自动命名，跳过 logo 和装饰图，同时生成一份下载清单（文件名、原说明文字、原图链接、状态）。

适合：图鉴、相册、产品图库、博物馆开放图库……任何"一页很多图、每张图下面有名字"的页面。

## 用法

需要 Python 3.8+，不用装任何包。

```bash
python grab_gallery.py "https://example.com/gallery/" "./保存文件夹"
```

可选参数：

| 参数 | 作用 |
| --- | --- |
| `--only /gallery/` | 只要原图链接里含这段文字的图 |
| `--names 对照.csv` | 两列 CSV（网页上的说明文字,新文件名），按你自己的规则改名 |
| `--min-kb 15` | 小于这个大小的图当缩略图跳过 |

同名的第二张自动加 `_2`。保存文件夹里会多一个 `00_清单.csv`。

## 让 AI 助手替你跑

把 `SKILL.md` 装进 Claude、Codex 等支持技能的 AI，或把正文贴进豆包、ChatGPT 的自定义指令，然后说：

```text
帮我把这个网页上的图全部存到「图片/参考图」文件夹，按每张图下面的名字命名，最后告诉我一共几张、有没有下载失败的：<网页地址>
```
