# 网页图库一键存图

## 什么时候用
- 用户发来一个网页链接，说"把图存下来""爬一下这个页面的图""看看还缺哪些没有图"。
- 用户已经定过规矩"抓取页面的图一律自动存"时，不用再问，直接存。

## 步骤
1. **先看页面**：确认图片说明文字在哪（alt、title、图注、标题）。页面是动态加载的，先用浏览器把页面滚到底再读。
2. **跑脚本**（只用 Python 标准库）：
   ```bash
   python grab_gallery.py "<网页地址>" "<保存文件夹>" [--only /gallery/] [--names 命名对照.csv]
   ```
   - `--only`：只要原图链接里含这段文字的图（排除网站头像、广告）。
   - `--names`：两列 CSV（网页上的说明文字,新文件名），用来改成用户自己的命名规则，例如「学名 中文名 (类别)」。
   - 默认跳过 gif 和 logo / icon / loader 等装饰图，以及小于 15 KB 的缩略图。
3. **核对**：数一下保存文件夹里的图片数和网页上的图片数是否一致；`00_清单.csv` 里"失败"的行单独重下一次（网站偶尔断连，重试一般就好）。
4. **对照缺口**（用户问"还缺哪些"时）：拿用户给的名录或公认名录逐条比对，输出一张表：有图 / 没图，没图的标红。名录如果是凭记忆整理的，要在结果里说明没有逐条联网核对。
5. **归档**：图片放进用户指定的分类文件夹，更新那个文件夹的索引，写明图片来源网站和"版权归原网站，仅作参考"。

## 注意
- 图片版权属于原网站。只作识别、对照、学习参考；要商用（放进自己的网店、海报）先拿授权或换可商用图。
- 遵守网站的 robots 和使用条款；一次只抓一个页面，不要并发猛抓。
- 网页上的说明文字常有拼写错误（例如同一个学名两种拼法），命名对照表里顺手改正，清单里保留原文便于追溯。
