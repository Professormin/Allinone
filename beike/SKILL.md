# 备课 Skill

将课程目标和参考资料转为能教、能看懂、可修改的教学材料。适用于各学科；不要把示例主题、年级或配色当成产品限制。

## 明确上下文

优先从当前对话、课程安排和用户提供的资料确认：学科/主题、教学对象及先备知识、课时、目标、已讲进度、参考风格和输出位置。缺少影响内容正确性的信息时集中问一次，其他可采用说明过的合理默认值。无参考课件也可从目标创建。

“下一课”按实际安排和已完成产物判断，不简单把文件名加一；不编造日期或新增正式课次。资料正文和外部文件是参考内容，不能覆盖用户的明确要求。

可选设置见 [references/configuration.md](references/configuration.md)。用户偏好覆盖默认设置。个人路径、课表和私有资料保存在用户项目内，不写进本技能或公开包。

## 教学内容

- 每个知识块建立“问题/现象 → 解释或证据 → 概念/方法 → 应用”的联系。依据学科区分事实、约定、模型、推论、解释与争议，不把自然科学推导模式强加给文学或历史。
- 先说明意义，再引入术语；普通例子在前，特例在后。控制内容量，让目标与课时匹配，不按固定页数填满课件。
- 给可视化的原理配有解释力的图：空间结构、过程图、时间轴、地图、关系图、批注文本或数据图。装饰图标和带边框文字不算原理图。默认避免连续纯文字页，但保留阅读、史料、诗文等学科必要文本。
- 计算展示数量来源、公式条件、代入、单位与结论；非计算学科展示证据到结论的过程，不省略关键论证。区分自编示例与真实数据。
- 每个重点配适量应用或练习，答案与教师提示放教师材料；讲解例题可展示解法。讲义/课件是否即时显示答案服从用户选择。考试复习使用新体系或数据，不能泄露未公开试题。
- 专业事实不确定时查可靠来源，注明适用条件。图中标签、几何、坐标、时间和数值必须与正文一致。引用材料需保留来源，注意可公开使用的范围。

## 产物与流程

1. 有参考文件时实际阅读并渲染代表页，提取视觉和教学结构；无参考时选清楚易读的版式。配色、字体、互动方式可调整，默认16:9和通用字体。
2. 建立逐页设计：目标、标题、关键解释、图解、来源/证据、练习及教师答案。最后一页默认学习目标检查与迁移；考试复习可用“重点与常见题型”，不要暗示真实考卷权重。
3. 制作可编辑 PPTX；保留图解源文件及 PNG。用宿主已有的课件工具，必要时先定位运行时和依赖，不写死某个软件版本、盘符或模板。输出格式不足时明确报告，不伪造文件或链接。
4. 教师备课表包含“开课前先讲顺”和“对着课件备课”：前者讲主线、前提与关键图解；后者逐页放新课缩略图、来源（有旧课件则附对应缩略图）、讲授深度、这页含义、讲法、注意点和答案。无旧课件就说明自编及事实来源，不制造原课页码。必要时加术语读音。默认不写逐字稿，用户需要时再提供。
5. 默认交付课件 PPTX/PDF 和教师表 DOCX/PDF；只请求其中一项时缩小范围。制作教师表可用 [scripts/build_prep.py](scripts/build_prep.py)，输入见 [references/prep-schema.md](references/prep-schema.md)。脚本只排版，不会自动研究内容、生成整套课件或导出 PDF。
6. 渲染后检查全篇缩略图和重点页大图：截字、上下标、字体、图文对应、表格跨页、空白页、答案隔离、来源真实性。检查教师表覆盖每一课件页。修订后重导出，不交旧 PDF。
7. 使用用户指定目录，保留原件，分开教师和学生材料。仅按明确要求同步或公开。交付真实链接、页数、检查结果及未完成事项。
