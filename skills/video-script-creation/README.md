# Geek Empire · Original Video Script Creation v2.3

Original, knowledge-rich and creator-voiced spoken video scripts. This module is **separate from copywriting rewriting and 二创**.

## Structure
- script-router: picks ONE dominant rhetorical mechanism based on the viewer's intended takeaway, not a topic keyword.
- dialogue-comedy: quick dialog, reversals, literal misunderstandings.
- causal-monologue: thesis, causal progression, decisive finish.
- deep-mechanism: example, cognitive conflict, layered mechanisms.
- practical-tutorial: hands-on and repeatable instructional steps.
- ai-tool-review: verified features and concrete use cases.
- comparative-sales: contrasts, evidence and buying decisions.
- iris-voice-dna: creator read-aloud retakes, careful final editing.

## Two independent assessment dimensions
**A. Creator aesthetics and voice fit:** user-picked reference scripts are positive subjective curation signals, not evidence of view counts. Preserve characteristic oral phrasing after read-aloud revisions; do not infer endorsement of every fact in a reference.

**B. HKRR:** Happiness 快乐; Knowledge 知识; Resonance 共鸣; Rhythm 节奏. Score each 1–10 with a reason and actionable edits. Assess initial draft, then approved final trim. Scores reflect editorial judgments, NOT verified retention, completion rates or viral predictions. Do not flatten creator's voice to chase HKRR scores.

Workflow: topic → route → draft → HKRR draft review → creator reads/rephrases repeatedly → recognize retakes and clean transcription → creator declares final editing → restrained final cut → HKRR post-cut review → archive versions.

New-chat maintenance: open latest files in this GitHub module before updating; classify new examples into an existing structural family unless a genuinely novel and repeatable mechanism warrants a new skill. GitHub never synchronizes automatically between chats; push only on request.

## Privacy
This is a PUBLIC repository. Do NOT upload full third-party transcripts, raw personal audio, client information, or private stylistic revision logs. Keep a separate local or private source library with traceable reference IDs. Only anonymized/generalized analysis and reusable writing instructions belong here. Original-script and rewrite/二创 systems must remain separate.
