# Dialogue Comedy
A concrete question → counterintuitive reply → plausible objection → escalating misunderstanding or sharp reversal → concise payoff.
Substyles within ONE skill: incisive counter-questions, straight-faced absurdity, literal reinterpretation. Each exchange adds information or surprise; finish before the joke goes stale. Prefer distinct voices, spoken brevity and natural timing. Do not reuse original third-party punchlines. Critique ideas without stigmatizing vulnerable people. User-curated models: animal interview, far-away marriage Q&A, misunderstood class subject, surname conversation.
HKRR emphasis: Happiness and Rhythm; factual fairness and viewer Resonance still matter.
