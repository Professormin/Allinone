# Practical Tutorial
Immediate goal → required setup → visible step 1/2/3 → common error → result.
Give gestures, device angles, UI labels or menu paths only when verified. Keep steps executable and visual, not padded with promotion. A product mention should not displace learning.
Model reference concept: three ways to position a phone camera for relaxed short videos.
HKRR emphasis: useful Knowledge and followable Rhythm.
