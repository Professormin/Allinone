# prompt：说一个词，按当前对话推荐提示词

提示词存了一堆，用的时候想不起来、找不到？装上这个技能后，在对话里说一句 **prompt**，AI 会：

1. 看你最近几轮在做什么；
2. 只读你提示词库的索引，挑 3–4 条最对口的；
3. 做成“左划 / 右划 / 收藏”的选择卡片让你点；
4. 把你选中的提示词空位用对话内容自动填好，给你一段能直接复制的提示词；
5. 记下你每次的选择，用得越多推荐越准；都不合适就现写一条，问你要不要存进库。

## 安装
复制这句话发给支持技能的 AI（Claude、Codex 等）：

```text
请帮我安装「prompt」技能：https://github.com/Professormin/allinone/tree/main/prompt
```

或在 Claude 网页 / 桌面版上传 [`zip/prompt-v0.1.0.zip`](../zip/)。

## 准备提示词库
- 设环境变量 `PROMPT_LIB_ROOT` 指向你的提示词库文件夹；不设也行，第一次用时 AI 会问你一次。
- 库的格式照 [`templates/`](templates/)：一个 `00_索引.md`（每条一行），加按分类分开的 `提示词/<分类>.md`。

## 说明
- 只推荐库里真实存在的提示词；现写的会标“新写，未入库”。
- 只读索引和被选中的条目，省 AI 额度。
- “左划右划”是用选择题卡片模拟的，不是手势滑动；没有选择题工具的 AI 会改成编号列表。
